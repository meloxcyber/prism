Your PCPRISM.bat pulls on launch

Code changes arrive via git pull when you start PRISM. App-list changes arrive even without a restart of the repo: the assistant fetches /apps.json from this site on start-up. Personal entries go in apps.local.json and are never overwritten.

Set up on a new PC

1 · Prerequisites

  • Python 3.10+ with “Add to PATH” ticked
  • Git for Windows
  • Claude Code — run claude once and sign in

2 · Get PRISM

git clone https://github.com/meloxcyber/prism
then double-click install.bat.

Optional: copy config.local.example.json → config.json to change the voice, clap sensitivity or mic.

3 · Run

Double-click PRISM.bat and clap twice. PRISM.bat --calibrate tunes the clap threshold for your room; autostart.bat launches it at sign-in.
