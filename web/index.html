Setup & updates

New PC
  1. Python 3.10+ (tick “Add to PATH”) and Git for Windows
  2. Claude Code — run claude once and sign in
  3. git clone https://github.com/meloxcyber/prism → install.bat
  4. PRISM.bat → the HUD opens → clap twice
Update flow

Ask Claude → commit to GitHub → Vercel rebuilds this console and /apps.json → PRISM.bat pulls on launch. Your config.json and apps.local.json are never overwritten.
